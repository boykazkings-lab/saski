# سوق البيت — مشروع تطبيق Android أصلي

هذا مشروع Android مكتوب بـ Java وواجهات Android الأصلية. لا يستخدم صفحة ويب داخل التطبيق.

## ما يفعله

- يعرض منتجات منزلية في أقسام: المواد الغذائية، الخضر والفواكه، الحليب والأجبان، اللحوم، التنظيف، المطبخ، العناية، البيت والديكور، الأطفال، المفروشات، الصيدلية، الأجهزة الصغيرة، والحيوانات الأليفة.
- يتيح البحث وتصفية المنتجات حسب القسم وتغيير الكميات.
- يحفظ السلة ورقم الهاتف على الجهاز باستخدام التخزين المحلي.
- يجهّز رسالة SMS فيها المنتجات والكميات والمجموع التقريبي. يفتح تطبيق الرسائل، ويؤكد المستخدم الإرسال من الهاتف.
- لا يطلب صلاحية إرسال الرسائل تلقائيًا؛ الإرسال يتم بعد مراجعة الرسالة والضغط على زر الإرسال.

## إنشاء ملف APK

1. ثبّت Android Studio على كمبيوتر Windows أو Mac أو Linux.
2. فك ضغط مجلد المشروع ثم افتح مجلد `SouqAlbayt` من Android Studio.
3. اسمح لـ Android Studio بتنزيل Gradle و Android SDK Platform 35 عند الطلب.
4. اختر **Build → Build APK(s)**.
5. سيظهر APK التجريبي في `app/build/outputs/apk/debug/app-debug.apk`.
6. انقل الملف إلى هاتف Android وافتحه. قد يطلب Android السماح بالتثبيت من هذا المصدر.

للنشر الرسمي، استخدم **Build → Generate Signed Bundle / APK** وأنشئ مفتاح توقيع خاصًا واحتفظ به في مكان آمن.

## ملاحظات

- الأسعار الموجودة أمثلة بالدينار الجزائري؛ عدّلها في `app/src/main/java/dz/souqalbayt/MainActivity.java` قبل الاستخدام الفعلي.
- المشروع يحتاج Android Studio واتصالًا لتنزيل أدوات البناء أول مرة.
- لا يتضمن المشروع ملف APK مبنيًا؛ بيئة إنشاء هذا الملف لم يتوفر فيها Android SDK أو Gradle.


## إنشاء APK دون تثبيت Android Studio (باستخدام GitHub Actions)

يمكن بناء APK على خوادم GitHub السحابية من المتصفح:

1. أنشئ حسابًا مجانيًا في GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا (New repository)، واجعله Private إذا أردت إبقاء المشروع خاصًا.
3. ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على المجلد `souq-albayt-android` ومجلد `.github`.
4. افتح تبويب **Actions** في المستودع.
5. اختر سير العمل **Build Souq Albayt APK** ثم اضغط **Run workflow** إذا لم يبدأ تلقائيًا.
6. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
7. نزّل `SouqAlbayt-debug-apk.zip`، ثم فك ضغطه لتحصل على `app-debug.apk`.
8. انقل APK إلى هاتف Android وثبّته. قد تحتاج إلى السماح بالتثبيت من مصدر المتصفح أو مدير الملفات.

ملاحظة: هذه نسخة Debug للتجربة. قبل النشر العام، أنشئ نسخة Release موقّعة بمفتاح خاص واحتفظ به بأمان.
